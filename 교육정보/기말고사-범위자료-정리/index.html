시험과 복습 · 학생과 학부모

기말고사 범위 정리: 교과서·필기·추가 자료를 한 목록에 모으기

기말고사 범위 정리는 어떤 자료의 어느 부분을 봐야 하는지 찾는 목록부터 만들면 됩니다. 교과서만 체크하고 학교에서 배부한 자료나 수업 메모를 빠뜨리지 않도록 묶어 보세요. 내용을 이해하는 작업과 자료를 모으는 작업을 구분합니다.

01 · 실행하기

학교 안내의 최신 범위 옮기기

과목별 단원·쪽수·포함 자료와 시험 날짜를 기록합니다. 범위 안내의 날짜도 남겨 바뀐 내용을 비교하세요. 친구가 전해 준 범위는 학교의 실제 안내와 대조합니다.

교과서의 모든 내용이나 학원 교재의 목차를 자동으로 시험 범위에 넣지 않습니다. 확실하지 않은 제외·포함 항목은 질문 칸에 둡니다.

02 · 실행하기

단원마다 자료의 위치 연결하기

단원 이름 옆에 교과서 쪽수, 학교 자료 제목, 수업 필기 날짜, 관련 과제를 적습니다. 파일이면 저장 위치를, 종이면 묶어 둔 위치를 남겨 공부할 때 다시 찾는 시간을 줄입니다.

같은 내용을 다룬 자료라도 필수 안내와 보충 자료를 나눕니다. 추가 자료는 설명이나 적용을 돕는 용도로 사용하고 확정 출제 정보로 받아들이지 않습니다.

03 · 실행하기

자료 확보와 이해 확인을 다른 표시로 남기기

자료를 찾았다는 표시와 내용을 설명하거나 풀 수 있다는 표시를 따로 둡니다. 빈 자료가 있으면 먼저 학교 안내에 맞게 보충하고, 이해가 막힌 자료에는 질문을 붙입니다.

색칠한 칸이 많다는 이유로 공부를 마쳤다고 보지 마세요. 실제 과제의 수행을 확인한 날짜와 남은 질문이 있어야 합니다.

04 · 실행하기

범위가 바뀌면 원본 목록에서 수정하기

새 안내를 받으면 수정된 항목과 날짜를 원래 목록에 반영합니다. 여러 시간표와 사진을 따로 보관하다가 이전 범위를 공부하는 일을 줄일 수 있습니다.

목록이 완성되면 가장 먼저 확인할 단원과 자료를 골라 공부를 시작합니다. 목록을 꾸미는 데 대부분의 시간을 쓰지 않도록 합니다.

내 자료에 적용해 보기

사회 한 단원의 목록을 “교과서 해당 쪽 / 학교 배부 지도 자료 / 수업 비교 표 / 제출 과제”로 만들고, 각 항목에 확보 여부와 혼자 설명 가능한지를 따로 표시합니다. 지도 자료가 없으면 범위를 임의로 지우지 말고 배부·열람 방법을 확인합니다.

실제 학생의 성과 사례가 아닌 설명용 예시입니다. 자신의 교과서와 과제에 맞춰 사용하세요.

공부를 마친 뒤 확인할 질문

  • 최신 범위 안내와 대조했나요?
  • 각 자료를 다시 찾을 위치가 있나요?
  • 자료 확보와 이해 상태를 따로 표시했나요?

학부모는 이렇게 도와주세요

부모가 자료를 대신 정리하기보다 아이가 빠진 것을 찾도록 도와주세요. 인쇄나 파일 확인처럼 필요한 지원은 하되, 학생의 이해는 실제 설명과 답안으로 확인합니다.

자주 묻는 질문

문제집 한 권을 다 보면 범위를 확인한 건가요?

학교 범위와 포함 자료가 문제집과 다를 수 있습니다. 실제 안내를 기준으로 대조하세요.

범위 목록은 매일 새로 써야 하나요?

원본 목록에 변경 날짜와 이해 상태를 갱신하면 됩니다. 자료 찾기와 공부를 연결하는 용도로 사용하세요.
