학부모와 상담 · 학생과 학부모

학원을 다녀도 공부가 막힐 때, 학습 코칭에서 물어볼 것

수업을 오래 들었는데도 공부가 어려우면 먼저 어디에서 연결이 끊기는지 확인하세요. 수업 이해, 숙제 시작, 오답 수정, 다음 과제 선택은 서로 다른 도움을 필요로 할 수 있습니다. 코칭이라는 이름만으로 해결이나 성적 변화를 보장할 수는 없습니다.

초등 · 중등 · 고등내용 확인 2026.10.05
이 글에서 확인할 것막히는 과정을 자료로 보여 주기피드백이 다음 행동으로 이어지는지 묻기계획과 실행 사이의 부담 살피기상담의 목표를 확인 가능한 것으로 정하기연습 예시와 점검학부모의 도움질문과 답참고 자료← 교육정보 전체

01 · 실행하기

막히는 과정을 자료로 보여 주기

최근 숙제와 시험지에서 같은 문제가 반복되는 장면을 고릅니다. 설명은 이해하지만 혼자 시작하지 못하는지, 과제를 끝내도 오류가 남는지 나누세요. 기록이 없으면 한 과제를 해 보며 시도한 단계와 멈춘 곳을 남깁니다.

02 · 실행하기

피드백이 다음 행동으로 이어지는지 묻기

잘못된 답을 알려 주는 것 외에 이유를 설명하고 다시 해 볼 과제가 있는지 확인합니다. 학생이 같은 오류를 반복할 때 어떤 자료를 다시 보는지도 질문하세요. 피드백은 받았다는 사실보다 학생이 수정에 사용할 수 있는지가 점검 대상입니다.

03 · 실행하기

계획과 실행 사이의 부담 살피기

학교 숙제·수업·이동·수면을 함께 놓고 실제 복습 자리를 확인합니다. 지키기 어려운 계획을 의지의 문제로만 보지 않습니다. 과제 크기나 질문 통로를 바꾸었을 때 실행이 어떻게 달라지는지 볼 수 있는 방식인지 묻습니다.

04 · 실행하기

상담의 목표를 확인 가능한 것으로 정하기

첫 과제, 수정할 학습 행동, 다시 볼 자료를 기록합니다. 단기간 성적 상승을 약속하는 말보다 학생이 어떻게 설명하고 다시 확인할지를 살펴보세요. 담당 과목·학년·방식·비용은 해당 지점에서 실제 운영을 확인합니다.

내 자료에 적용해 보기

영어 지문을 읽은 뒤 답만 확인하는 학생이라면 코칭 질문은 “매일 몇 지문?”보다 “틀린 답의 근거를 어떻게 표시하고 다음 지문에서 확인하나요?”가 될 수 있습니다. 같은 지문에서 고친 답과 다른 지문에서의 수행을 함께 보는 예시입니다.

실제 학생의 성과 사례가 아닌 설명용 예시입니다. 자신의 교과서와 과제에 맞춰 사용하세요.

  • 점검 자료와 실제 운영 조건을 확인했나요?

학부모는 이렇게 도와주세요

현재 수업을 부정하는 말로 시작하지 말고 반복되는 자료와 필요한 도움을 보여 주세요. 학생의 부담과 질문 방식도 상담에 포함합니다.

자주 묻는 질문

개별 코칭이면 반드시 성적이 오르나요?

학생 상태와 실제 지원 방식에 따라 달라지며 성적 변화를 보장할 수 없습니다. 확인할 학습 행동과 자료를 먼저 정하세요.

수업을 바로 바꾸어야 하나요?

현재 수업에서 받을 수 있는 도움과 실행 조건을 먼저 확인하세요. 바꿀 요소를 정한 뒤 실제 운영을 비교합니다.
