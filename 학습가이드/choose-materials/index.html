01 · 먼저 확인

지금의 자료에서 시작하세요

유명한 교재나 많은 수업이 현재 질문에 꼭 맞는 것은 아닙니다. 학교 범위와 필요한 학습 목적을 먼저 적고, 자료의 설명·예제·문제 난도가 현재 수행에 맞는지 표본으로 확인해 보세요. 선택 뒤에도 실제 소요 시간과 확인 기회가 충분한지 다시 봅니다.

  • 선택하려는 자료가 해결할 질문이 분명한가요?
  • 예제 설명을 이해한 뒤 비슷한 문제를 혼자 해 볼 수 있나요?

02 · 실행 순서

오늘 해 볼 네 가지 행동

  1. 목적을 한 줄로 적기

    기초 개념 설명, 학교 범위 적용, 독해 근거 찾기 등 지금 필요한 활동을 정합니다. 교재 권수나 선행 진도만 목표로 쓰지 않습니다.

  2. 몇 쪽 표본 확인하기

    현재 단원에서 설명과 예제를 읽고 유사 과제를 해 봅니다. 전혀 시작하지 못하는지, 도움 뒤 가능한지 구분합니다.

  3. 확인 구조 비교하기

    답안만 있는지 이유 설명과 질문 기회가 있는지 봅니다. 스스로 적용할 과제와 재확인할 자료가 있는지도 확인합니다.

  4. 시도 후 조정하기

    실제 사용 시간과 남은 질문을 기록합니다. 자료가 목적에 맞지 않으면 분량을 더하기보다 필요한 설명·난도·방법을 다시 선택합니다.

03 · 연습 예시

설명을 실제 행동으로 바꾸기

연습용 예시: 문장 구조 이해가 목적이라면 긴 단어 목록 중심 자료와 구문 설명 뒤 새 문장 확인이 있는 자료를 비교합니다. 표본을 해 보고 어느 단계에 도움을 받을 수 있는지도 적습니다.

실제 학생 사례가 아닌 설명용 예시입니다. 자신의 자료에 맞게 바꿔 사용하세요.

04 · 나의 기록

오늘의 확인을 짧게 남기세요

학교·이름 없이 학습 내용만 적어도 충분합니다. 다음 행동 한 가지를 찾는 데 사용하세요.

빈 기록 양식 받기 ↓ TXT

기록은 전송하거나 자동 보관하지 않습니다. 페이지를 떠나기 전에 TXT로 저장하세요.

다음에 확인할 것

선택 뒤 짧은 사용 기록을 보고 질문이 구체화됐는지, 현재 수행에 맞는 지원이 있었는지 점검하세요.

05 · 함께 돕기

학부모는 이렇게 도와주세요

주변 학생이 사용하는 자료보다 현재 질문을 기준으로 함께 비교하세요. 추가 수업을 검토할 때는 독립 수행 시간과 전체 일정도 봅니다.

적용할 때 확인하세요

가이드의 비교 기준은 특정 교재·수업의 추천이나 비용 정보가 아닙니다. 실제 조건은 제공처와 확인합니다.

자주 묻는 질문

어려운 교재를 써야 빨리 느나요?

현재 이해와 필요한 도움에 맞는 자료가 필요합니다. 난도만으로 판단하지 않습니다.

교재를 끝내야 바꿀 수 있나요?

목적과 맞지 않거나 필요한 설명이 없으면 사용 범위·지원 방법부터 조정할 수 있습니다.
